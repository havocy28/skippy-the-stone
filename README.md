# Skippy the Stone

Skip a little stone across the pond, make some friends, and get him home.

**Play:** https://havocy28.github.io/skippy-the-stone/ (also on itch.io: https://havocy28.itch.io/skippy-the-stone)

On iPhone, browsers can't go fullscreen. Open the play link, tap Share, then Add to Home Screen, and Skippy opens from his icon with no browser bars.

This repository only holds the built game (v0.1.1). Made with three.js; fonts are Grandstander and Nunito (SIL Open Font License, see the *-OFL.txt files).
